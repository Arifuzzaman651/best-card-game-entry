Ember Court — an original duel card battler: flame, sword and leaf cards, 3 energy a turn, chains, shields and a Warden who plays in the open. First to 0 life loses the Court.

## Run it

```sh
node serve.ts
```

Then open http://localhost:8080 in a desktop browser. Or open game/index.html directly — it plays with no network. Click a card or press 1–5 to play, Space ends the turn, R restarts, M mutes.
